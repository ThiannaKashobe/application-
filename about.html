Prototype de dashboard pour le suivi du CA, des ventes, de la trésorerie et des stocks.

Retour au tableau

Présentation

Ce prototype permet de visualiser un tableau de bord simplifié pour un commerce (Café Congo SARL). Les données sont fournies localement via data.json et chargées par le navigateur.

Utilisation

  1. Servir le dossier via HTTP (nécessaire pour que fetch('data.json') fonctionne) : python -m http.server 8000.
  2. Ouvrir http://localhost:8000 dans le navigateur.

Note sur le Chiffre d'affaires

Le graphique d'évolution utilise le champ history et les KPI sont calculés à partir de sales. Si history n'est pas actualisé, le graphique peut afficher une valeur différente du total des ventes : le prototype inclut maintenant une correction manuelle dans data.json ou peut synchroniser automatiquement la valeur du jour à partir des ventes.
